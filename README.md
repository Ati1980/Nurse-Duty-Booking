## 🔄 ลำดับขั้นตอนการจองเวร 2 รอบ (Workflow)

```

                     │
                     ▼ (Admin เปิดรอบที่ 2 เมื่อเวรยังไม่ครบ)
              [รอบที่ 2: แสดงเฉพาะเวรที่ยังว่างจากรอบ 1]

                     ▼
              [Admin กดปุ่ม Optimize จัดตารางเวรอัตโนมัติ]
                     │  (ระบบเกลี่ยเวรให้ครบทุกกะ และเกลี่ยภาระงานให้เท่าเทียม)
                     ▼
              [ตารางเวรเสร็จสมบูรณ์ / พิมพ์ A4 / ส่งออก Excel]
```

## ⚡ ระบบ Optimize จัดตารางเวรอัตโนมัติ (Auto Optimizer)
เมื่อ Admin กดปุ่ม **⚡ Optimize จัดตารางเวรอัตโนมัติ**:
1. นำความประสงค์ใน **รอบที่ 1** มาจัดวางเป็นอันดับแรก
2. นำการลงชื่อรับเวรเพิ่มใน **รอบที่ 2** มาเติมเต็มเวรที่ว่าง
3. หากยังมีกะที่ขาดคน อัลกอริทึมจะคัดเลือกพยาบาลที่มีชั่วโมงเวรสะสมน้อยที่สุดเข้ามาเติมเต็มอัตโนมัติ
4. มีระบบตรวจสอบความปลอดภัย (Safe Rest Rules): หลีกเลี่ยงเวรดึกต่อด้วยเวรเช้าในวันถัดไปทันที
5. รายงานผลสรุปเปอร์เซ็นต์ความครอบคลุม (Coverage 100%) และจำนวนเวรเฉลี่ยต่อคน
